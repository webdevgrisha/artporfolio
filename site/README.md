# NOT.YET.KNOW.ARTIST Site

The public site, built with Astro and rendered on the server. Its structure is described in [ARCHITECTURE.md](../docs/ARCHITECTURE.md#public-site-astro).

Copy `.env.example` to `.env` before the first run.

Run commands from the repository root:

```bash
pnpm dev:site
pnpm check
pnpm build
```
