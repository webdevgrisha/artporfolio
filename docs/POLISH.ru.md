# Чек-лист полировки

Цель проекта: публичный сайт, а за ним и админка, ощущаются как премиальный цифровой продукт, где продумана каждая мелочь. Этот список — условие готовности каждой страницы и каждого компонента. Страница не готова, пока по ней не пройден весь список.

Премиум здесь — сдержанность и точность, а не количество эффектов: безупречная основа и несколько фирменных моментов. Сайт монохромный, цветные на нём только работы, и интерфейс не спорит с ними.

Правила вёрстки и токены описаны в [STYLE_GUIDE.ru.md](STYLE_GUIDE.ru.md). Этот документ о том, как страница ощущается.

## 1. Отклик и скорость

- [ ] Нажатие отвечает сразу, в пределах 100 мс: состояние нажатия, начало перехода, индикатор.
- [ ] Переход между страницами плавный (View Transitions), а не мигание белым.
- [ ] Следующая страница подгружается при наведении на ссылку, поэтому открывается мгновенно.
- [ ] Core Web Vitals на телефоне при медленной сети: LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1.
- [ ] Только самая крупная картинка первого экрана грузится с `priority`, остальные лениво.
- [ ] Скрипты не мешают первой отрисовке: страница читается и без JavaScript.

## 2. Ничего не прыгает

- [ ] У каждой картинки есть размеры или пропорции, поэтому место под неё оставлено заранее.
- [ ] Шрифт не сдвигает текст, когда загрузится (запасной шрифт подогнан под Absans).
- [ ] Выбранная тема не мигает другой при загрузке.
- [ ] Открытое меню или диалог не сдвигает страницу в сторону (`scrollbar-gutter`).
- [ ] Сообщения формы появляются в заранее оставленном месте, а не толкают то, что под ними.

## 3. Картинки

- [ ] Пока фото грузится, на его месте спокойная заглушка, а загруженное фото плавно проявляется, а не появляется скачком.
- [ ] Формат AVIF, иначе WebP, нужной ширины (`sizes` честный), чёткий на retina.
- [ ] Цвета работ точные: профиль цвета сохранён, P3 не обрезан до sRGB.
- [ ] Кадрирование не режет главное в работе. Работа целиком показывается без обрезки.
- [ ] `alt` описывает, что изображено. Декоративное фото с `alt=""`.

## 4. Движение

- [ ] Только токены `--motion-*`: одни длительности и одна кривая на всём сайте.
- [ ] Что появляется, то и уходит, той же дорогой и с той же скоростью.
- [ ] Анимацию можно прервать на середине: она разворачивается от текущего места, а не доигрывается до конца.
- [ ] Двигаются только `opacity`, `translate`, `scale`, `clip-path`, без анимации размеров и раскладки.
- [ ] Каждое всплывающее (меню, список, подсказка) открывается и закрывается анимацией, одинаково для всех.
- [ ] При `prefers-reduced-motion: reduce` ничего не едет и не увеличивается, а результат тот же.
- [ ] Скролл нативный: никакой подмены скролла, прелоадеров, звука.

## 5. Состояния

У каждого интерактивного элемента продуманы:

- [ ] покой, наведение (только при `hover: hover`), нажатие, фокус с клавиатуры (`:focus-visible`), выключенный;
- [ ] текущая страница или выбранный вариант (`aria-current`, `aria-checked`);
- [ ] отправка, успех, ошибка, нет сети.

У каждой страницы и блока продуманы:

- [ ] загрузка, пусто (нет работ, нет фото), ошибка API, очень длинный текст, очень короткий текст;
- [ ] самый длинный язык (немецкий, финский) и письмо справа налево (арабский, иврит).

## 6. Типографика

- [ ] Только токены `--font-size-*`, `--line-height-*`, `--letter-spacing-*`.
- [ ] Заголовки сбалансированы (`text-wrap: balance`), абзацы без висящего одного слова (`pretty`).
- [ ] Короткие предлоги и союзы не остаются в конце строки (неразрывный пробел) там, где это правило языка.
- [ ] Кавычки, тире и многоточие правильные для языка («», „“, —, …), а не `"` и `-`.
- [ ] Строка текста не длиннее `--text-max-inline-size`.
- [ ] Крупный текст выровнен по оптическим краям: по капителям и базовой линии (`text-box`), а не по коробке строки.

## 7. Мелочи браузера и устройства

- [ ] Выделение текста в цветах сайта (`::selection`).
- [ ] На телефоне нажатие не даёт серую вспышку (`-webkit-tap-highlight-color`). Вместо неё своё состояние нажатия.
- [ ] Цвет адресной строки (`theme-color`) совпадает с фоном в обеих темах.
- [ ] Иконка вкладки читается на светлой и тёмной вкладке. Есть иконка для домашнего экрана телефона.
- [ ] Ссылка, отправленная в мессенджер или соцсеть, приходит карточкой с картинкой страницы (`og:image`).
- [ ] Курсор `pointer` только у того, что нажимается.
- [ ] Печать страницы не выводит меню и кнопки.

## 8. Доступность — тоже качество

- [ ] Всё доступно с клавиатуры в логичном порядке. Фокус виден и не прячется под шапкой.
- [ ] Контраст текста не ниже 4,5:1, крупного — 3:1, в обеих темах.
- [ ] Цель для пальца не меньше `--min-tap-target-size`.
- [ ] Скринридер читает страницу осмысленно: заголовки по порядку, у кнопок-иконок есть названия.
- [ ] Страница работает при увеличении до 200% и при крупном шрифте браузера.

## 9. Проход полировки

После каждой страницы, перед тем как назвать её готовой:

1. Реальный iPhone в Safari и Android в Chrome, а не только эмуляция в DevTools.
2. Медленная сеть (Slow 4G) и пустой кеш.
3. Обе темы, `prefers-reduced-motion`, клавиатура без мыши.
4. Ширины: 320px, сразу до и после 40rem и 75rem, 1920px и шире.
5. Самый длинный язык и язык справа налево.
6. Lighthouse и Core Web Vitals.

## Фирменные моменты

Несколько интерактивных решений, ради которых сайт запоминается. Каждое делается вместе со страницей, к которой относится.

1. **Превью «вырастает» в работу.** Картинка из сетки галереи плавно превращается в большую на странице работы (общий `view-transition-name`). Вместе со страницей галереи и страницей работы.
2. **Зум до мазка.** Работу можно приблизить до фактуры холста, на телефоне жестами. Вместе со страницей работы.
3. **Работа в реальном масштабе.** Её размер видно относительно человека или комнаты. Вместе со страницей работы.
4. **Появление при скролле.** Тонкое, на CSS (`animation-timeline: view()`), без библиотек.

## Первая проверка, 12 ноября 2026

Проверены готовые части: шапка, меню, футер, рассылка, контакты, страницы ошибок. Основа сильная: ничего не прыгает, тема не мигает, состояния ссылок и формы продуманы, меню открывается анимацией, движение уважает `reduced motion`, `text-wrap` задан в reset.

Не хватает:

- [x] плавного перехода между страницами (View Transitions) — раздел 1;
- [x] подгрузки страницы при наведении на ссылку — раздел 1;
- [x] плавного проявления фото и заглушки в цвете самой работы вместо серой — раздел 3;
- [x] анимации у списков языка и валюты: они появляются скачком, а меню разворачивается — раздел 4;
- [x] плавной смены темы: сейчас она мгновенная — раздел 4;
- [x] `::selection` и `-webkit-tap-highlight-color` — раздел 7;
- [x] `og:image`: ссылка на сайт приходит в мессенджер без картинки — раздел 7;
- [ ] иконки вкладки для тёмной вкладки и иконки для домашнего экрана — раздел 7;
- [x] неразрывных пробелов после коротких слов в текстах из API — раздел 6.
