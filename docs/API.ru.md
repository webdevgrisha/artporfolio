# API

Эндпоинты Cloud Function `api`. Обновляйте этот файл в том же коммите, что и эндпоинт.

## Общие правила

- Все пути начинаются с `/api`, тела запросов и ответов — JSON, если не сказано иное.
- **Сессия.** `POST /api/auth/login` ставит httpOnly-cookie `admin_session`. Эндпоинты с пометкой *Сессия* без действующей сессии администратора возвращают `401`.
- **CSRF.** Эндпоинтам с пометкой *CSRF* нужен заголовок `X-CSRF-Token` с токеном из `GET /api/auth/csrf`, иначе они возвращают `403`. Токен привязан к сессии, поэтому после входа запросите новый.
- **Проверка.** Некорректное тело возвращает `400`. Неизвестные поля отклоняются. Параметр пути, который ничего не называет, например неизвестная страница, возвращает `404`.
- **Ошибки** имеют один формат:

  ```json
  { "error": { "code": "UNAUTHORIZED", "message": "Authentication required" } }
  ```

  Непредвиденные ошибки логируются и возвращаются как `500 INTERNAL_SERVER_ERROR`.

## Health

### `GET /api/health`

`200 { "status": "ok" }`

## Авторизация

### `GET /api/auth/csrf`

Выдаёт CSRF-токен и ставит соответствующую cookie.

`200 { "csrfToken": string }`

### `POST /api/auth/login`

*CSRF.* Обменивает Firebase ID token на сессию администратора.

```json
{ "idToken": "…" }
```

| Статус | Результат |
| --- | --- |
| `200` | `{ "user": { "email": string \| null, "uid": string } }`, ставит cookie сессии |
| `401` | Не администратор, или пароль вводили больше 5 минут назад |

### `GET /api/auth/me`

*Сессия.* `200 { "user": { "email": string | null, "uid": string } }`

### `POST /api/auth/logout`

*CSRF.* Удаляет cookies сессии и отзывает сессию. Успешен и без сессии.

`204`, без тела.

## Изображения

Загруженные фото возвращаются как `Image`:

```ts
interface ImageSource {
  url: string; // ссылка Firebase на скачивание, кешируется на год
  width: number;
}

interface Image {
  fileName: string; // имя загруженного файла
  fileSize: number; // размер загруженного файла в байтах
  width: number; // размер самого большого изображения
  height: number;
  sources: { avif: ImageSource[]; webp: ImageSource[] }; // по возрастанию ширины
  version: string;
}
```

Загружается JPEG или PNG до 15 МБ и 50 мегапикселей с именем файла до 255 символов. WebP и AVIF
отклоняются: они уже сжаты для веба.

Загруженное фото уменьшается без обрезки до ширин 640, 960, 1280 и 1920 (не шире оригинала) и
сохраняется в AVIF и WebP. Ориентация из EXIF применяется, все метаданные, включая геолокацию,
удаляются. Оригинал хранится закрыто, чтобы позже пересобрать изображения.

## Контакты

```ts
interface Contacts {
  email: string;
  instagram: string;
  linkedin: string;
  youtube: string;
}
```

Пустая строка означает, что контакт на сайте не показывается.

### `GET /api/contacts`

Публичный. Пока контакты ни разу не сохраняли, возвращает пустые строки, а пока не загружено
фото — `photo: null`.

`200 { "contacts": Contacts, "photo": Photo | null }`

### `PUT /api/contacts`

*Сессия, CSRF.* Заменяет все контакты целиком. Все поля обязательны.

- Пробелы по краям обрезаются.
- `instagram`, `linkedin`, `youtube`: пусто или `http(s)`-ссылка с доменом.
- `email`: пусто или адрес почты.

`200 { "contacts": Contacts }` с сохранёнными значениями.

## Фото для контактов

```ts
interface Photo extends Image {
  alt: string;
}
```

### `PUT /api/contacts/photo`

*Сессия, CSRF.* Загружает или заменяет фото. Тело — `multipart/form-data`:

| Поле | Значение |
| --- | --- |
| `file` | Изображение, см. [Изображения](#изображения) |
| `alt` | Обязательный, 1–250 символов после обрезки пробелов |

| Статус | Результат |
| --- | --- |
| `200` | `{ "photo": Photo }` |
| `400` | Нет файла или alt, неподдерживаемое или слишком большое изображение, слишком длинное имя файла |
| `413` | Файл больше 15 МБ |

Предыдущее фото удаляется после сохранения нового.

### `PATCH /api/contacts/photo`

*Сессия, CSRF.* Меняет alt, не загружая фото заново.

```json
{ "alt": "…" }
```

| Статус | Результат |
| --- | --- |
| `200` | `{ "photo": Photo }` |
| `404` | Фото нет |

### `DELETE /api/contacts/photo`

*Сессия, CSRF.* Удаляет фото и его файлы. Успешен и когда фото нет.

`204`, без тела.

## Страницы

Страницы публичного сайта, которые открываются главным фото (hero): `home`, `gallery`, `projects`,
`about`, `contacts`. Любая другая `:page` возвращает `404`.

```ts
interface Page {
  hero: Image | null; // null, пока главное фото не загружено
}
```

Главное фото — фон под названием страницы, поэтому alt у него нет.

### `GET /api/pages`

Публичный. Возвращает все страницы.

`200 { "pages": { "home": Page, "gallery": Page, "projects": Page, "about": Page, "contacts": Page } }`

### `PUT /api/pages/:page/hero`

*Сессия, CSRF.* Загружает или заменяет главное фото страницы. Тело — `multipart/form-data` с одним
полем `file`: изображение, см. [Изображения](#изображения).

| Статус | Результат |
| --- | --- |
| `200` | `{ "hero": Image }` |
| `400` | Нет файла, есть другое поле, неподдерживаемое или слишком большое изображение, слишком длинное имя файла |
| `404` | Неизвестная страница |
| `413` | Файл больше 15 МБ |

Предыдущее фото удаляется после сохранения нового.

### `DELETE /api/pages/:page/hero`

*Сессия, CSRF.* Удаляет главное фото и его файлы. Успешен и когда фото нет.

| Статус | Результат |
| --- | --- |
| `204` | Без тела |
| `404` | Неизвестная страница |
